# AGENTS.md — Kelseir Project Context

## Overview
Asynchronous, production-ready Telegram bot ("kelseir") for YouTube audio extraction.

## Tech Stack
- **Language**: Python 3.12 (managed via `uv`)
- **Frameworks**: aiogram 3.x, Taskiq
- **Database**: PostgreSQL 16, SQLAlchemy 2.0 (Async), Alembic, greenlet
- **Infrastructure**: Docker Compose, Redis, yt-dlp, ffmpeg
- **Quality**: Ruff, Mypy, Loguru, Pydantic Settings

## Project Structure
- `bot/` — Telegram bot logic, handlers, middlewares
- `worker/` — Taskiq background tasks (downloading, processing)
- `core/` — Config, database engine, models, shared utilities
- `migrations/` — Alembic migration scripts

## Code Conventions & Rules
- **Async First**: All I/O operations (DB, HTTP, File) must be fully asynchronous.
- **Git Flow**: Work in feature branches (`feature/issue-X-...`), PR into `develop`, merge to `main` for releases.
- **Config**: Managed via `pydantic-settings` in `core/config.py`.
- **Database**:
  - Always use `AsyncSession`.
  - Base metadata in `core/db.py`, models in `core/models.py`.
  - Migrations generated via `make migrate-create msg="..."`.

## Useful Commands (Makefile)
- `make db-up` / `make db-down` — Infrastructure management
- `make migrate` — Apply Alembic migrations
- `make migrate-create msg="..."` — Generate autogenerated migration
